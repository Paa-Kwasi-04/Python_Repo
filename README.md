# Python_Repo

This repository is a collection of Python learning work and small-to-medium projects, organized into three main areas.

## Repository Structure

### 1) `ATM Simulation`
- Console ATM simulation implementations in Python and C.

### 2) `Python_Projects`
Personal projects focused on practical application building:

- **Expense_Tracker**: Track and categorize expenses with CSV-based storage.
- **Number_guessing**: Number guessing game with score tracking.
- **Simple_Calculator**: Infix-to-postfix calculator (CLI + GUI files included).
- **Student_Grade_Manager**: Manage student scores, grades, and reports with CSV support.
- **ToDo_List**: Task manager using JSON persistence, due dates, tags, and status tracking.
- **Weather_App**: Weather data app using an external API and environment variables.
- **Personal_ML_Projects**: Notebook-based ML projects (e.g., churn, diabetes, salary prediction).

### 3) `Python_Mosh`
Course-based practice and mini-projects from Python learning modules:

- **Learning**: Topic-focused exercises (control flow, functions, classes, exceptions, APIs, regex, DSA, unit testing, data structures, virtual environments).
- **Projects**: Mini apps and scripts (currency converter, password generator, quiz game, tic-tac-toe, crawler, selenium, PDF tools, and more).

## Notes

- Many projects are standalone and can be run from their own folders.
- Some projects require external dependencies (`Pipfile`/`requirements.txt`) or API keys/environment variables.
- Build artifacts and caches are present in some folders (`dist`, `build`, `__pycache__`).
